Project Overview
The Car Rental Reservation and Vehicle Return Management System is a DBMS-based application designed to manage car rentals efficiently. It handles customers, vehicles, branches, 
reservations, rentals, inspections, damages, invoices, payments, and rate plans through a structured MySQL database. The system uses a Python-based interface connected 
to the database and provides features such as vehicle availability, reservation management, pickup and return inspection, charge calculation, reporting, and CRUD operations.
Tech Stack: Python, Tkinter/ttk, MySQL, SQL, mysql-connector-python, Visual Studio Code, and GitHub.
